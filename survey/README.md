# 综述报告

本目录是 6 页中文综述《从 InstructGPT 到推理模型与智能体：大语言模型后训练方法的技术演进（2022—2026）》的交付版本。

- `后训练技术演进综述_2022-2026.docx`：可编辑源文件。
- `后训练技术演进综述_2022-2026.pdf`：最终阅读/打印版。
- `图1_2022-2026后训练技术演进.png`：独立高分辨率技术演进图。

报告结构：后训练目标的四次迁移 → 算法谱系（SFT、PPO/RLHF、DPO、GRPO、RLVR、多阶段与 Agentic/PARL）→ 数据与奖励机制 → 五个模型案例（R1、Qwen3、V3.2、K2.5、GLM-5）→ 共同趋势与条件依赖。

主要来源：InstructGPT、DPO、DeepSeek-V3、DeepSeek-R1、Qwen3、DeepSeek-V3.2、Kimi K2.5、GLM-5 技术报告，以及 GRPO/DeepSeekMath 与 PPO 原始论文。
